# v1.0.0 — Lead Capture & Inquiry Management

> **First Stable Release**  
> Plugin Version: **1.0.0**  
> DB Version: **1.3**  
> Status: **Final Review Passed / Stable Release**

## 1. 发布定位

`v1.0.0` 是 WP AI Chat Lab 第一版正式稳定 Release。它继承并正式发布已经在 `v0.9.0` 完成真实 WordPress 验收的完整能力，不重新改变已封板的 Chat、Lead、Inquiry、Usage 或 Provider 业务边界。

核心链路：

```text
Knowledge
→ Retrieval
→ Grounding
→ Usage Guard
→ Public Chat
→ Lead Trigger
→ Inline Inquiry Form
→ Public Inquiry REST
→ wp_wpaic_inquiries
→ Inquiry Admin Management
```

## 2. 正式能力

- DeepSeek Provider 与统一 AI Manager；
- Generic WordPress Knowledge + Local Retrieval；
- Strong / Medium / Weak / None Grounding；
- Conversation / Visitor / Site Usage Guard；
- Public Chat REST、Simple Chat UI、Request Guard 与 Provider Failure Boundary；
- 后台可配置 `commercial_intent` 关键词；
- `manual / commercial_intent / no_answer / usage_blocked` Lead Trigger；
- Inline Inquiry Form；
- `POST /wp-json/wpaic/v1/inquiry`；
- 独立 `wp_wpaic_inquiries`；
- Server Validation、Honeypot、Visitor Inquiry Rate；
- Inquiry 未读/已读、详情自动已读、搜索、来源筛选、批量已读/未读；
- Trash / Restore / Permanent Delete / Empty Trash；
- Stored XSS、Source URL、Nonce、非法 ID、Unicode / 特殊字符搜索等边界验证。

## 3. 从 v0.9.0 到 v1.0.0

这是一次 **稳定版本晋级**，不是重新开发。

```text
Plugin Version: 0.9.0 → 1.0.0
DB Version:     1.3   → 1.3
Schema:         unchanged
```

历史 `v0.9.0 Stage / Round` 文档、Lab 与注释继续保留，用于教学、诊断和版本回归。

## 4. 测试与生产注意事项

真实开发与验收使用 COODEC 官网公开内容及对应 WordPress 数据作为企业站样本：

- https://www.coodecglobal.com/

README 中的产品型号、Query、Retrieval Score、Coverage、Token、Usage Limit 与 Inquiry 数据属于测试快照，不应直接作为其他网站的生产固定值。上线前应重新确认：

- WordPress Timezone；
- DeepSeek API Key / Provider 连接；
- Knowledge Preview / Full Sync；
- Conversation / Visitor / Site Usage Limits；
- Public Request Guard；
- Inquiry Submission Rate；
- Commercial Intent Keywords；
- Provider Failure Lab = Idle；
- 测试 Counter / 测试 Inquiry 清理；
- Chat Widget 桌面端与手机端；
- Privacy Policy 与个人信息保留策略；
- HTTPS / Cloudflare / WAF。

## 5. 明确不包含

`v1.0.0` 不包含：

- CRM Pipeline；
- Sales Owner Assignment；
- Lead Tags；
- Human Handoff；
- Agent；
- RAG；
- Vector Database；
- 服务器端完整 Conversation Archive；
- 自动销售邮件通知。

## 6. Future Hardening

以下能力继续作为后续版本的回归扩展，不阻塞 v1.0.0：

- Dedicated DB `1.2 → 1.3` Migration Validation Lab；
- Inquiry Repository DB Failure Injection Lab。

建议后续版本从 `v1.0.1` 或 `v1.1.0` 继续，而不是继续修改已经发布的 `v1.0.0` 标签历史。
